# The shared kit: rules and reviews

The kit is `art-kit.js` (palette, scenery helpers, figures) and `game.js` (game plumbing and motion helpers). It exists to save effort on things journeys really share. It must not decide what a journey looks like.

## Fit first

- **Design the scene from the text, before looking at the kit.** Decide what each illustration should show for this story. Only then check whether a kit piece fits that picture.
- **Use a kit piece only when it is what you would have drawn anyway.** A cloud is a cloud. But don't put the adventurer in a story about Suriname or tea, a princess where the text has none, or a sparkle where the scene doesn't need one, just because they exist.
- **Draw new things freely.** Most of each journey's art should still be its own. If a kit piece almost fits, draw your own version in the journey rather than bending the story to it, and note it in the log below.
- **Keep journeys distinct.** If a new journey starts to look like the last one (same figure, same layout, same props), change it.
- The house style (warm paper, muted greens, flat shapes) is the one thing every journey shares; that comes from the palette, not from reusing figures.

## Review every three journeys

The kit is reviewed after every third new journey, with `/kit-review` (`.agents/skills/kit-review/SKILL.md`). It is a separate step once the journey is committed, so it never holds up a journey.

Once a review is due, every new journey ends with a reminder to run it, until a review has been done. Skipping is fine: the reminder simply comes back after the next journey.
