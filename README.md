# Alex’ thee-avontuur

Een persoonlijk Nederlands leesavontuur, speciaal voor Alex, van papa Jeremy.

## Openen

Met Node.js 18 of nieuwer, voer in deze map uit:

```sh
npm start
```

Open vervolgens [het thee-avontuur](http://localhost:3000).

## Wat zit erin?

- De vier oorspronkelijke alinea’s en drie begripsvragen uit `09-26-alex-reading.md` worden rechtstreeks ingelezen.
- Vier geïllustreerde hoofdstukken, woordverklaringen en zeven extra meerkeuzevragen.
- Open vragen met voorbeeldantwoorden om zelf of samen met papa te vergelijken. Deze worden niet automatisch beoordeeld.
- Uitleg bij elk quizantwoord, een persoonlijke afsluiting en de mogelijkheid om opnieuw te oefenen.
- Rustige leesstand, grotere letters, toetsenbordbediening en ondersteuning voor verminderde beweging.
- Voortgang en antwoorden blijven lokaal bewaard in deze browser. Er worden geen antwoorden verstuurd.

De illustraties zijn originele lokale SVG-tekeningen. De berg wordt geanimeerd met GSAP, dat lokaal in `vendor/` staat. Alleen de lettertypen worden van Google Fonts geladen; zonder internet gebruikt de pagina de ingebouwde vervangende lettertypen. Er zijn geen installatiepakketten nodig. De webserver luistert alleen op de eigen computer.
