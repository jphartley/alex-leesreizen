# Achter de schermen: Hoe werkt jouw website alex-reads.ink?

Heb je je wel eens afgevraagd hoe een website eigenlijk werkt? Als jij naar alex-reads.ink surft om een nieuw verhaal te lezen, gebeurt er op de achtergrond van alles in een fractie van een seconde. Jouw computer werkt dan samen met drie belangrijke systemen.

1. Het telefoonboek van het internet (DNS)
Elke computer en website op het internet heeft een eigen, uniek nummer. Dat noemen we een IP-adres (bijvoorbeeld 192.168.1.50). Omdat wij mensen niet zo goed zijn in het onthouden van lange getallen, gebruiken we namen zoals alex-reads.ink. Het DNS (Domain Name System) is het telefoonboek van het internet. Zodra jij de websitenaam intypt, zoekt het DNS bliksemsnel het juiste IP-nummer erbij, zodat jouw apparaat weet met welke computer hij moet 'bellen'.

2. Het digitale magazijn (GitHub)
Maar hoe komen die teksten op het internet? Dat begint op de laptop van degene die de website bouwt. Zodra een verhaal klaar is, wordt de code naar GitHub gestuurd. GitHub is een soort slim digitaal magazijn of kluis voor programmeurs. Door middel van een actie die we een 'push' noemen (het Engelse woord voor duwen), wordt de allernieuwste versie van de website veilig naar GitHub gestuurd.

3. De computer die nooit slaapt (Railway)
Nu staat de code in het magazijn, maar mensen kunnen het nog niet als een mooie website zien. Daarvoor gebruiken we Railway. Dat is een 'hosting tool': eigenlijk gewoon een hele krachtige computer (een server) die dag en nacht aan staat. Railway is gekoppeld aan GitHub. Zodra er een nieuwe tekst wordt 'gepusht', krijgt Railway een seintje, pakt de nieuwe code uit het magazijn en zet het direct live op het internet.

Dus: jij typt de naam in, het DNS vindt het nummer, en Railway laat jou de nieuwste teksten zien die via GitHub zijn verstuurd. Zo kun jij altijd direct beginnen met lezen!
